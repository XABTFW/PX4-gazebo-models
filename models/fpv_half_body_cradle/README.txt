容纳与地面支撑
--------------
* 模型原点仍在世界地面原点；内部 link 绕 Y 轴旋转 -90 度。
* 总高约 1.29 m，约为飞机可见机身长度的三倍；桶身截面约 0.34 x 0.54 m。
* 开口中心位于世界 X/Y=0，内壁 X/Y 半宽约 0.16/0.26 m（机身每侧约 1 cm 间隙）。
* 支撑面世界 Z=1.1835 m，开口边缘世界 Z=1.2935 m。
* 沿世界 +Z 出口没有盖板或横梁；机身正常朝上，不翻转飞机姿态。
* 机臂、桨叶、摄像头露在外面；不改变原飞机的碰撞体、动力或控制逻辑。
* 没有旧的大平台、四柱架和前部隐形支脚。直立外壳靠底端的薄底板接地，
  底板 visual/collision 对应；这属于简化地面支撑，不是实际手持测试。
* 一个独立自由刚体 link，质量 2.32 kg，正定惯性矩阵，重力开启。
* 精细 OBJ 仅为 visual；collision 使用简化 box/cylinder。
* 没有连接飞机的关节、发射机构、弹射力或控制插件。
  飞机离槽后外壳留在地面，不与飞机绑定。

场景与初始位置
--------------
default.sdf 中的模型 include 不变，仍在世界原点。
4023 默认 PX4_GZ_MODEL_POSE 改为 0,0,1.0135,0,0,0，使飞机碰撞底部从 z=1.2135 m
开始，略高于支撑面；自由落座后飞机模型原点约 z=0.9835 m。
显式设置 PX4_GZ_MODEL_POSE 时仍保留用户值。旧版显式 z=0.16/0.22/1.71 不再适用，
请改为 1.0135 或取消该显式设置，否则可能生成在外壳里面。

必须完整重载 Gazebo 场景和重启 4023，不能只重启 PX4 并连接旧世界。
没有替用户停止、重载正在运行的仿真，也没有发送任何起飞指令。
其他位置测试时，请把外壳 include/pose 和飞机生成位置一起平移。

单独放入其他世界：
  <include>
    <uri>model://fpv_half_body_cradle</uri>
    <pose>0 0 0 0 0 0</pose>
  </include>

资源路径需包含当前项目 Tools/simulation/gz/models。
